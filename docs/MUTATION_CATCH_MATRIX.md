# P0-A Mutation 捕获矩阵（v2, 含 G2b 整改与注入器 v2）
依据: 联合技术结论第二条——11门+28关系须通过Mutation准入测试;
验收口径: 安全/商品关键适用故障100%被至少一个预期门捕获; 附阴性对照/漏检/不可观测/未覆盖。
工具: mutation_matrix_pixel.py(像素域) + MUT_POSTSOLVE 注入器v2(lifestyle_scene.py, 默认no-op)
矩阵数据: output/commercial/mutation_catch_matrix.json

## 注入面

1. **像素域**(对 v17 定稿数值变换, 零渲染成本): 直接测"门能否从成品图发现已知故障类"
2. **规格域**(改 specs/*.json 重跑场景构建): P0-A 首轮结论=**求解器吸收效应**,
   solve_layout 把 xy 级故障修复(间隙门在 spec 面不可击穿)——这是求解器设计能力, 非门缺陷
3. **世界域 v2**(MUT_POSTSOLVE, solve后/测量前直接改对象, 强制 view_layer.update + rt.measure 重测):
   门只吃注入后新鲜世界状态, 杜绝 stale meas(测器测错对象事故类)
