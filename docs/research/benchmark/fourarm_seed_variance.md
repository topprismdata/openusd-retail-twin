## 读法与边界
- **本表的 n 与口径是唯一事实源**: 其它脚本 (38 号域对齐臂 / 43 号形状臂) 一律从这里引用配对差值与 CI, 不自己另算一遍; 闸门 28 号也只与本表对账, 不硬编码期望值。
- 复跑 (seed 43/44) 的数据、协议 (10 ep / 640 / batch 4 / max_det 1000)、权重选择口径 (best.pt) 全部与 2026-11-08 那版一致, 只换训练 seed → 差值里只剩训练随机性。
- **R2 − R0 就是'向全真实训练集追加 160 张合成图'这个操作的效应**; 配对 CI 跨 0 → '未检出差异'是数据支持的结论 (而不是单次运行的运气), 但 CI 的宽度同时告诉我们这个结论**能排除多大的效应**。
- **历史协议 (2026-11-08) 的那一对不能当 seed 复跑**: 那一版的 r1/r2 用的是旧合成划分(2026-11-21 换成场景级留出), 且跑在 macOS/MPS 上 → 它与当前协议的复跑**不是同一个实验**。证据: 纯合成臂 r1 在旧协议下是 0.1330, 换合成划分后是 0.2265 / 0.2437 / 0.2532。所以 README 里那个 'Δ = −1.77pp' 只能当**历史协议的观测值**引用, 不能当当前协议的效应量。
- 训练非逐字节可复现 (同配置两次权重 sha256 不同), 单 seed 差值本身就有运行噪声。
- r1 (纯合成) 只有 160 张合成图, 方差天然比另外两臂大; 它的负结论是'跨域纯合成不可用', 不因 seed 改变方向。
