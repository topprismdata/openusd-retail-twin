# 输入扰动探针: 合成模型卡在哪条通道上 (2026-11-25)

真实 test 前 800 张, 只扰动输入 (标签原样), 两个模型分别评。

| 扰动 | synth_R1 mAP50 | real_411 mAP50 |
|---|---|---|
| 原图 (参照) | 0.2305 | 0.7870 |
| 高斯模糊 σ=2 (削高频) | 0.2478 | 0.7893 |
| 高斯模糊 σ=4 (削更多高频) | 0.2427 | 0.7714 |
| JPEG 质量 30 重编码 (丢高频+块效应) | 0.2305 | 0.7858 |
| 加高斯噪声 σ=20 (补高频) | 0.1963 | 0.7556 |
| 降采样到 50% 再放大 (丢细节) | 0.2437 | 0.7907 |

**相对原图的变化 (pp)**

| 扰动 | synth_R1 Δ | real_411 Δ |
|---|---|---|
| 高斯模糊 σ=2 (削高频) | +1.73 | +0.24 |
| 高斯模糊 σ=4 (削更多高频) | +1.22 | -1.56 |
| JPEG 质量 30 重编码 (丢高频+块效应) | -0.01 | -0.12 |
| 加高斯噪声 σ=20 (补高频) | -3.42 | -3.13 |
| 降采样到 50% 再放大 (丢细节) | +1.32 | +0.37 |

**结论**: 合成模型在扰动后的真实图上**涨分** -> 卡点在**高频/纹理通道**: 真实照片的高频细节在误导它 -> 该做的是给合成图补高频 (PASTA/照片退化)
