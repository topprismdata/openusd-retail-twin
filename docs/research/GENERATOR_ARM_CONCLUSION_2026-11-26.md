## 一句话结论

**"让合成图更像真实货架"这条路不但没用，而且会让真实域迁移更差**：上下文质感单独
改成"有纹理、带价签、带隔板、暗环境"（其余逐项不变）掉 **10.1 pp**（CI [−16.33,
−3.87]，n=5，显著）；把整个域按真实货架重写（再加相机/密度/光照/货位错位）掉
**23.5 pp**（CI [−24.72, −22.34]，n=5，显著）。机制查实了：不是模型训崩（合成域内仍
0.995 ✓），而是**到了真实照片上整体不自信**——真实域召回整体掉到约 1/3；整域重写
那条还额外把形状先验收窄了。**"不动生成器、改训练"那条路（I-19）方向对但幅度不够**：
训练时抹掉一半训练图的上下文只有 **+1.5 pp**（CI [−0.78, +3.79]，n=5，未检出差异）。

## 1. 先把缺口定量（I-16，63 号探针）

真实 test 图里**标注框的区域原样保留、框外全部换成纯色底**（用 GT，只做诊断）：

1. 真实照片的**上下文**是当前模型在真实域上的**主要干扰源**（值 22.76 pp，是密度

## 4. 机制（65 号，现算）

真实 test 120 张，检出框与 GT 按 IoU≥0.5 配对，按 GT 面积占比分桶算召回：

| GT 面积占比 | 对照 R1 | I-17 | I-18 |
|---|---:|---:|---:|
| < 0.001 | 0.0155 | 0.0032 | 0.0056 |
| 0.001–0.0025 | 0.2452 | 0.0123 | 0.0750 |
| 0.0025–0.006 | 0.4843 | 0.0072 | 0.1579 |
| 0.006–0.015 | 0.4648 | 0.0009 | 0.1435 |
| > 0.015 | 0.2432 | 0.0000 | 0.0270 |
| 总体召回 | 0.3215 | 0.0082 | 0.1023 |

- **I-18 不是"定义收窄"，是"整体变保守"**：五个桶的相对比例与对照几乎一致（都约掉到

- **I-17 是整体塌掉**（各桶都接近 0），同时检出框宽高比中位 0.385 vs 对照 0.487

## 4b. I-19「训练时抑制上下文依赖」臂——方向对，但**未检出差异**

I-17/I-18 把"改生成器"关掉了，但**机制**还指向一条没试过的路：**不是让合成域的上下文
更像真实，而是让模型的商品定义不依赖上下文**。做法（`66_context_suppress_arm.py`）：
拿**已发布的 legacy 池**（不重渲），训练集里 **57% 的图把框外像素换成随机纯色**
（每通道 40-140，不用固定色免得模型学成新捷径），框内像素与标签原样，**验证集原样**，
图数/像素/标签/训练配方与 R1 对照臂逐项相同 → **唯一变量 = 一半训练图的上下文被抹掉**。

| seed | 对照 R1 (control_last) | 上下文抑制臂 (arm_last) | Δ (pp) |
|---|---|---|---:|
| seed 43 | 0.2436 | 0.2364 | −0.72 |
| seed 44 | 0.2532 | 0.2966 | +4.35 |
| seed 45 | 0.2294 | 0.2459 | +1.65 |
| seed 46 | 0.2598 | 0.2679 | +0.81 |
| seed 47 | 0.2436 | 0.2582 | +1.45 |

→ Δ(上下文抑制臂−对照) = **+1.51 pp**，mean +1.51pp，95% CI [−0.78, +3.79]，n=5
（4/5 seed 为正）→ **CI 跨 0 = 未检出差异**。

**能站住的结论只有一条**：**"训练时抑制上下文依赖"没有把迁移拉回可用区间**（CI 上界
+4.13 pp，远小于上下文本身值的那 22.76 pp）。两种解释都还活着：① 确实有一点点正收益，
但效应量（≈ +1.5 pp）需要更大的 n 才判得出来（按实测 seed 间 sd ≈ 2.3 pp，要让 CI
不含 0 需要 **n≈12**）；② 效应量就是接近 0（合成域的上下文既提供定位线索又塑造商品
定义，抹掉它的收益被"训练信号变弱"抵消）。

**机制探针（67 号）把这两个解释直接判掉了** —— 把对照模型与 I-19 模型都放到"真实原图
vs 剥离上下文的真实图"上评（同一份 300 张 ✓，配对 ✓）：

| 臂 − 对照（n=5） | 均值 | 95% CI |
|---|---:|---|
| 剥离版（没有上下文的真实照片） | **+3.83 pp** | [+2.50, +5.16] |
| 真实原图（有杂乱上下文的真实照片） | **+1.41 pp** | [−0.68, +3.50] |
| 上下文依赖度（剥离版 − 原图） | **+2.42 pp** | [+0.005, +4.83] |

- **干预是有效的**：模型在"没有上下文的真实照片"上**显著变强**（+3.83 pp，CI 整段 > 0 ✓）
  → 商品定义确实变得更不依赖上下文 ✓；
- **但没打在病根上**：同一批模型在"有杂乱上下文的真实照片"上只涨 +1.41 pp ✓ → **上下文的
  伤害一点没消除** ✓（依赖度不降反升 +2.42 pp ✓ —— **该 CI 下端只比 0 高 0.005 pp, 属于擦边 ✓**）。
→ **所以真实域的损失不是"模型太依赖上下文"，而是"模型处理不了杂乱的上下文"** ✓✓ ——
训练侧把上下文拿掉治不了这个病 ✓（与 I-17/I-18 合看：把上下文做得更像真实 → 更差 ✗；
把上下文拿掉 → 没用 ✗）→ 剩下的门只有"让训练里出现真实上下文"（真实数据进训练 ✓，
或生成器产出既真实又不误导的上下文 ✓）。

## 5. 这对"合成数据能不能提升真实域"意味着什么
1. **缺口是真实的**（域内 0.995 vs 跨域 0.24，差 74.66 pp），**而且它主要在上下文
   上**（22.76 pp）。
2. **但"把合成域的上下文做得更像真实"不能补它**——反而掉 10.1 pp（I-18，n=5 显著）；
   连整域重写都掉 23.5 pp（I-17，n=5 显著）。
3. **而"训练时抑制上下文依赖"也不够**——I-19 测得 +1.51 pp，CI [−0.78, +3.79]
   （**未检出差异**）：方向对，幅度远小于 22.76 pp 的缺口。**机制探针（67 号）进一步说明
   为什么**：干预确实让模型在"没有上下文的真实照片"上显著变强（+3.83 pp，CI 整段 > 0），
   但在"有杂乱上下文的真实照片"上只涨 +1.41 pp → **真实域的损失不是"太依赖上下文"，
   而是"处理不了杂乱上下文"**（依赖度反而 +2.42 pp）。
4. 因此本仓的结论升级为：**在不引入真实照片的前提下，把合成域往真实域方向改，只会
   让"合成→真实"的鸿沟更大**；负结论已被推到"合成域怎么改都没用"这一层
   （与此前排除的框统计量、密度 ~4 pp、照片颗粒、噪声、增强、场景多样性、训练期模糊、
   商品表面、合成剂量↑ 构成完整排除链）。**剂量这条也独立封口**：大池剂量轴在
   **5% 与 2% 两个预算**上各 8 档 × 3 seed 全跑完，斜率 **−0.086 / −0.167 pp/100 张**
   （都平坦略负），框量等效的 2240 档 −2.34 / −4.57 pp，且 1280 档以上 seed 间方差
   爆炸（sd 0.060-0.071）。
5. **下一轮该往哪走（按机制，不是按直觉）**：探针说明真实照片的上下文是**干扰项**
   （去掉它 +22.76 pp），而合成域里上下文**是有用的**（去掉它 −0.29 pp）——两者的
   差别说明模型在合成域里学到的"什么是商品"**依赖合成域的上下文**，到了真实照片
   上这个依赖失效。可操作的方向不是"模仿真实上下文"，而是**让训练信号与上下文无关**
   （I-19 已试，+1.51 pp 不够 ✗），或者**放弃让合成模型直接吃真实照片**，转做"合成
   数据只做预训练、真实标注做微调"这类**分工**路线。**两条都已经跑完并被否**（2026-11-27 补计，详见第 7 节）：
   ① **I-19 补到 n≈12** → **降级**（机制已经回答了“为什么”，n=12 只能把 +1.5 pp 钉死或钉死为 0，不改变结论）✓；
   ② **分工臂（I-20）** → **被否**：Δ = −2.01 pp，CI 整段在 0 以下（n=3，3/3 seed 全负）→ **合成预训练不仅没有正收益，还比同真实曝光的纯真实对照差 2 pp**✓。

## 7. 2026-11-27 补计: 两条新排除 (I-20 分工臂 / I-22 MixStyle)

这两条不属于“改合成域”，但同样是**排除链**，且各自对应一条**文献结论**，所以也记在这里。

### 7.1 I-20「合成数据只做预训练 + 真实标注做微调」的分工臂 —— **显著劣化**

臂 = 合成池预训练 10 ep → 5% 预算的 411 张真实图微调 10 ep；两个对照分别堵住两种质疑：
**ctrl_a** = 只用真实 10 ep（**真实曝光逐项相同**）、**ctrl_b** = 只用真实 20 ep（**总步数更多**）。
评测 = SKU-110K test split（与所有臂同一份）、last-vs-last、逐 seed 配对。

| seed | ctrl_a（只用真实 10 ep） | 分工臂 | Δ (pp) |
|---|---|---|---:|
| seed 43 | 0.7744 | 0.7555 | −1.89 |
| seed 44 | 0.7858 | 0.7668 | −1.90 |
| seed 45 | 0.7888 | 0.7665 | −2.23 |

Δ(分工臂−ctrl_a) = **−2.01 pp**, mean −2.01pp, 95% CI [−2.48, −1.53], n=3（3/3 seed 全负）→ **CI 整段在 0 以下 = 显著劣化**。
Δ(分工臂−ctrl_b) = −5.61 pp, CI [−7.60, −3.61] → **CI 整段在 0 以下 = 显著劣化** ✓（口径更正后 ✓）。

**为什么这个结果重要**：它不是“没有正收益”，而是**有害**——分工臂与 ctrl_a 的真实曝光逐项相同，唯一差异是先在合成池上训了 10 ep。
对 67 号探针给的“门”（让训练里出现真实上下文），这个结果回答了一半：**分工路线确实让真实上下文进了训练，却比不预训练的纯真实更差**。
**机制已由 67 号探针测过第一部分**（I-27 ✓，2026-11-27 12:31 完成 ✓）——“**污染了**”这半句被独立复现 ✓（300 张子集上 −2.03 pp，CI 整段在 0 以下 ✓），但“**污染 = 商品定义被绑到合成域的上下文**”这半句**未被证实** ✓（上下文依赖度之差 +1.05 pp，CI 跨 0 ✓）→ 更像**表征层面**的损伤 ✓。

**对文献的边界**：“少量真实数据 + 大量合成”在本项目**不成立**（混合口径 I-04 ✓ / 分工口径 I-20 ✓ 两个口径都负）→
它的前提“合成域与真实域本身就近”在本仓**是必要条件**，而不是自动成立的前提（本仓合成域距真实域 74.66 pp）。

### 7.2 I-22「MixStyle（特征级多样化）」臂 —— **文献那一格被否**

训练时对 backbone 前两个 C3k2 的输出做 MixStyle（官方实现，每样本每通道的 μ/σ 与打散后的 batch 按 Beta(0.1,0.1) 混合，eval 时关闭）；
数据/图数/像素/标签/配方与 R1 对照臂逐项相同 → **唯一变量 = 训练时的特征统计被扰动**。

Δ(MixStyle臂−对照) = **−1.08 pp**, mean −1.08pp, 95% CI [−2.33, +0.16], n=5（4/5 seed 为负）→ **CI 跨 0 = 未检出差异**（不是“显著为正”）。

**为什么这里值得写**：文献（arXiv 2610.00030 §5.1）说“增加变化性比提升视觉真实感更有效”，而本仓在**数据级**已经否掉它（I-09：photo −2.66 / augment+ −3.77 / mixed3 −6.05）→
I-22 把它在**特征级**也否掉了→ **“变化性”这条路（两个层级）在本项目里都不立**。
**可用的边界句**：“增加变化性”的效果依赖于**合成域本身已经足够真实**”；在这里合成域距真实域 74.66 pp，所以添加变化只会把领域拉开更远。

### 7.3 两条归并后，排除链的形状

它们把两个不同的东西混在一起了，但要分开看：

| | 涉及的规则 | 本轮结果 |
|---|---|---|
| I-20（分工） | 合成数据**作为先验资格**的位置 | 显著劣化 −2.01 pp（CI 整段 < 0）→ **合成数据不能占任何位置**（否则它只能在真实先验的位置被真实数据污染） |
| I-22（MixStyle） | **变化性**这个方向本身 | 未检出改善（Δ −1.08，CI 跨 0）→ **数据级 + 特征级两层都不立** |

**当前证据能支持的结论**：**在本仓的合成域与真实域相差 74.66 pp 的前提下，合成数据没有任何用法能提升真实域性能** ——不是“用法不对”，而是**每一种用法都实测为零或负**（混合✓ / 改合成域✓ / 微调自身✓ / 预训练✓ / 特征级多样化✓）。
