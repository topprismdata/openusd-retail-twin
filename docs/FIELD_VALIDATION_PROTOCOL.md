# 真实终端巡检校验协议 (P2, 预注册)

目的：为"合成训练替代手工标注"命题提供真实域验收闭环（docs/SYNTHETIC_VS_MANUAL_ANNOTATION.md §三.2）。
当前状态：**前置缺口 = 无真实终端图像**；本协议定义采集与验收规范，采集到位后即可执行，不允许用合成图冒充。

## 1. 采集规范
- 场景：≥3 家真实门店冷柜/端架，覆盖 3 种光照（日光灯/自然光/混合）。
- 设备：手机主摄 + 固定巡检相机各 ≥1；分辨率 ≥1080p；保留 EXIF。
- 数量：每状态分层 ≥50 张：合规 / OOS 空洞 / 朝向错位 / 竞品入侵（合计 ≥200）。
- 标注：双人独立框 + 第三人仲裁；记录标注工时（用于与合成零标注成本对照）。
- 元数据：门店/货架层/拍摄距离/光照/SKU 清单 → `field_meta.json`。

## 2. 验收指标（与 P0-1 同协议）
- 每状态分别报：准确率 / 误报 / 漏报（conf 0.35, max_det 1000）。
- OSA 与人工审计差异 ≤ 5 pp。
- 计数 MAE / MAPE / Pearson（对 facings）。
- 域偏移监控：上线后每月回流 50 张复评，mAP@0.5 漂移 > 3 pp 触发再训练。

## 3. 判读规则（预注册）
- 合成臂模型在真实集 mAP@0.5 ≥ 真实臂 - 2 pp → 合成替代成立（本场景）。
- 任一状态漏报率 > 15% → 该状态回退真实标注补充训练（主动学习队列）。
- 禁止用合成测试集结论外推到真实验收。

## 4. 产物
- `output/field_eval/<date>/` 原始图+标注+报告 json
- 报告入 README 账目与 reviews/ 归档
