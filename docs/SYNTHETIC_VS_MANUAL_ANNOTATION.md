# 合成样本（数字孪生 SDG）能否替代手工标记？成熟度研判

命题：用数字孪生/合成渲染样本训练 YOLO，是否可以替代传统手工标注？该方法是否成熟？
方法：联网文献+产线证据（2026-11-08）+ 本项目 P0-1 四臂实测（R0 训练中）+ GPT 联合研判（reviews 待归档）。

## 一、结论（先给答案）

**能替代"训练集的大规模手工标注"，不能替代"真实数据本身"。**

| 用途 | 能否用合成替代手工 | 成熟度 | 关键证据 |
|---|---|---|---|
| 训练集主体标注 | ✅ 替代（混合范式下仅需 10–100 张真实微调） | **产线成熟** | Eversberg2024: k=10 时合成预训练比纯真实 AP +30.5%；DBAL 25 张主动≈50 张随机 |
| 稀有/危险状态覆盖（OOS、错朝向、竞品入侵、遮挡极端） | ✅ 替代（真实几乎采不到） | **成熟** | 本项目 SDG 状态机 70/15/10/5%；Neurolabs dropout/instancing |
| 分割/遮挡率/计数等"难标真值" | ✅ 替代（像素级无人为误差） | **成熟** | CPGDet-129 掩膜+可见性过滤；本项目 P0-2 射线掩膜 |
| 验证集 / 域偏移监控 / 验收 | ❌ 必须真实+人工抽检 | 不可替代 | 合成测试集自证=循环论证（GPT 审计红线） |
| 长尾外观（污损/极端光照/新品类） | ⚠️ 部分（需真实回流补渲染资产） | 条件成熟 | fruit 论文域偏移下纯合成 0.51–0.57 |
| 纯合成零真实数据直接上线 | ⚠️ 仅限容忍 ~60% mAP 的定位类任务 | **条件成熟** | Neurolabs 纯合成真实测试 60% mAP 已产线（Auchan） |
| 完全去除真实数据且要求 parity | ❌ 不成熟 | 不成熟 | fruit: 纯合成 0.626–0.656 vs 真实 0.978+ |

## 二、量化证据表（固定真实测试集）

| 训练 regime | in-domain mAP@0.5 | 域偏移 mAP@0.5 | 来源 |
|---|---:|---:|---|
| 真实 50 张 | 0.978 | 0.748 | arXiv:2603.28670 (Isaac Sim, YOLOv8s) |
| 真实 100 张 | 0.983 | 0.703 | 同上 |
| 纯合成 1000 | 0.626 | 0.565 | 同上 |
| 纯合成 5000 | 0.656 | **0.510（更多合成反而更差）** | 同上 |
| 混合 1000+50 | 0.974 | 0.747 | 同上 |
| 混合 5000+100 | 0.984 | 0.680 | 同上 |
| 纯合成（零售货架） | 0.60（真实测试集） | — | Neurolabs CPGDet-129 产线 |
| 合成预训练+主动学习 k=10 | AP +30.5% vs 纯真实 | — | Eversberg & Lambrecht 2024 |

三条硬规律：
1. **混合 ≈ 真实**：合成+50–100 张真实即逼近全真实效果 → 手工标注量降 1–2 个数量级。
2. **合成数量 ≠ 质量**：域偏移下 5000 张纯合成劣于 1000 张 → 保真度/分布对齐比堆量重要。
3. **合成价值在低真实数据区最大**：真实数据越少，合成边际收益越高（主动学习进一步放大）。

## 三、对本项目的含义

- 我们的 SDG（02）+ P0-2 像素级标签 正处该范式正确位置：**训练集标注零人工**。
- 必须保留的人工环节（不可省）：
  1. 真实验证集（终端实拍 ≥200 张，四状态分层抽检）——P2 批次；
  2. 合成-真实标注分布一致性校验（Neurolabs 口径：bbox 面积/遮挡分布对比）——P0-3；
  3. 域偏移监控（上线后真实回流抽样复评）。
- 本项目自证数字（P0-1 四臂；协议 seed42/640/max_det1000/MPS；2026-11-08 内存止损修订 epochs 10/batch4，四臂同改）：
  - R0 真实基线：test mAP@0.5 **0.886** / mAP@0.5:0.95 0.528 / P 0.883 / R 0.807（与 shelf-monitor 参考 0.896/0.538 同量级，协议实现有效）
  - R1 纯合成：test mAP@0.5 **0.133** / 0.050 —— 强负结果：跨域纯合成不迁移（我们单货架域 vs SKU-110K 密集真实域；与 P0-3 分布差密度6×/面积2.4×/朝向单一因果一致）
  - R2 混合：跑中
  - R3 改进 SDG：待 P0-3 消融臂（尺度已校准 cam_mult1.6；密度因子需多联货架墙，另立 A1b）
  - 判读规则（预注册）：若 R2 ≈ R0（ΔmAP@0.5 ≤ 2pp）且 R1 < R0 → 命题成立为"混合范式替代训练集标注"（且须域对齐前提）；若 R2 ≈ R1 < R0 → 合成无增量，命题不成立。
  - R1 负结果已修正命题边界：**替代的前提是域对齐**；跨域纯合成=0.133 级失败，不得外推。

## 四、风险清单

1. 域偏移下堆合成反效果（fruit 证据）→ 控制合成规模+分布对齐，不堆量。
2. 纹理/几何保真决定上限（本项目程序化贴图天花板 87–89 视觉分）→ 高保真需求走品牌资产包/摄影测量。
3. 合成 bbox 与人工 bbox 语义差（紧贴 vs 留边）→ P0-2 紧致框 + 分布一致性校验。
4. 评估闭锁：禁止用合成测试集证明合成价值（GPT 审计红线）。
5. 类别语义：SKU-110K 单类"object" 只能证明"定位/计数"，不能外推到品牌/SKU 识别（GPT 提醒）。
