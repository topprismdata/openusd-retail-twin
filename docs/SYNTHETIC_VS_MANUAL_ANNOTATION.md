# 合成样本（数字孪生 SDG）能否替代手工标记？成熟度研判

命题：用数字孪生/合成渲染样本训练 YOLO，是否可以替代传统手工标注？该方法是否成熟？
方法：联网文献+产线证据（2026-11-08）+ 本项目 P0-1 四臂实测（R0 训练中）+ GPT 联合研判（reviews 待归档）。

## 一、结论（先给答案）

**能替代"训练集的大规模手工标注"，不能替代"真实数据本身"。**

| 用途 | 能否用合成替代手工 | 成熟度 | 关键证据 |
|---|---|---|---|
| 训练集主体标注 | ✅ 替代（混合范式下仅需 10–100 张真实微调） | **产线成熟** | Eversberg2024: k=10 时合成预训练比纯真实 AP +30.5%；DBAL 25 张主动≈50 张随机 |
| 稀有/危险状态覆盖（OOS、错朝向、竞品入侵、遮挡极端） | ✅ 替代（真实几乎采不到） | **成熟** | 本项目 SDG 状态机 70/15/10/5%；Neurolabs dropout/instancing |
| 分割/遮挡率/计数等"难标真值" | ✅ 替代（像素级无人为误差） | **成熟** | CPGDet-129 掩膜+可见性过滤；本项目 P0-2 射线掩膜 |
| 验证集 / 域偏移监控 / 验收 | ❌ 必须真实+人工抽检 | 不可替代 | 合成测试集自证=循环论证（GPT 审计红线） |
| 长尾外观（污损/极端光照/新品类） | ⚠️ 部分（需真实回流补渲染资产） | 条件成熟 | fruit 论文域偏移下纯合成 0.51–0.57 |
| 纯合成零真实数据直接上线 | ⚠️ 仅限容忍 ~60% mAP 的定位类任务 | **条件成熟** | Neurolabs 纯合成真实测试 60% mAP 已产线（Auchan） |
| 完全去除真实数据且要求 parity | ❌ 不成熟 | 不成熟 | fruit: 纯合成 0.626–0.656 vs 真实 0.978+ |

## 二、量化证据表（固定真实测试集）

| 训练 regime | in-domain mAP@0.5 | 域偏移 mAP@0.5 | 来源 |
|---|---:|---:|---|
| 真实 50 张 | 0.978 | 0.748 | arXiv:2603.28670 (Isaac Sim, YOLOv8s) |
| 真实 100 张 | 0.983 | 0.703 | 同上 |
| 纯合成 1000 | 0.626 | 0.565 | 同上 |
| 纯合成 5000 | 0.656 | **0.510（更多合成反而更差）** | 同上 |
| 混合 1000+50 | 0.974 | 0.747 | 同上 |
| 混合 5000+100 | 0.984 | 0.680 | 同上 |
| 纯合成（零售货架） | 0.60（真实测试集） | — | Neurolabs CPGDet-129 产线 |
| 合成预训练+主动学习 k=10 | AP +30.5% vs 纯真实 | — | Eversberg & Lambrecht 2024 |

三条硬规律：
1. **混合 ≈ 真实**：合成+50–100 张真实即逼近全真实效果 → 手工标注量降 1–2 个数量级。
2. **合成数量 ≠ 质量**：域偏移下 5000 张纯合成劣于 1000 张 → 保真度/分布对齐比堆量重要。
3. **合成价值在低真实数据区最大**：真实数据越少，合成边际收益越高（主动学习进一步放大）。

## 三、对本项目的含义

- 我们的 SDG（02）+ P0-2 像素级标签 正处该范式正确位置：**训练集标注零人工**。
- 必须保留的人工环节（不可省）：
  1. 真实验证集（终端实拍 ≥200 张，四状态分层抽检）——P2 批次；
  2. 合成-真实标注分布一致性校验（Neurolabs 口径：bbox 面积/遮挡分布对比）——P0-3；
  3. 域偏移监控（上线后真实回流抽样复评）。
- 本项目自证数字（P0-1 四臂；协议 seed42/640/max_det1000/MPS；2026-11-08 内存止损修订 epochs 10/batch4，四臂同改）：
  - R0 真实基线：test mAP@0.5 **0.886** / mAP@0.5:0.95 0.528 / P 0.883 / R 0.807（与 shelf-monitor 参考 0.896/0.538 同量级，协议实现有效）
  - R1 纯合成：test mAP@0.5 **0.133** / 0.050 —— 强负结果：跨域纯合成不迁移（我们单货架域 vs SKU-110K 密集真实域；与 P0-3 分布差密度6×/面积2.4×/朝向单一因果一致）。**⚠️ 2026-11-23 注**：0.133 属于**旧合成划分**的历史协议；当前协议（场景级留出 + Windows/CUDA）复跑为 0.2265 / 0.2437 / 0.2532 —— 负结论不变，但引用具体数字时要注明协议版本
  - R2 混合：跑中
  - R3 改进 SDG：待 P0-3 消融臂（尺度已校准 cam_mult1.6；密度因子需多联货架墙，另立 A1b）
  - 判读规则（预注册）：若 R2 ≈ R0（ΔmAP@0.5 ≤ 2pp）且 R1 < R0 → 命题成立为"混合范式替代训练集标注"（且须域对齐前提）；若 R2 ≈ R1 < R0 → 合成无增量，命题不成立。
    **⚠️ 2026-11-23 复核**：这个 ≤2pp 阈值的**余量只有 0.23pp，而臂间 seed 波动达 1.79pp** → 阈值判据本身不成立；改用按 seed 配对的 CI：当前协议 Δ(R2−R0) = +0.11 / +0.04 / +0.25 / +0.23 pp（mean +0.15，CI [−0.00, +0.31]，n=4，补 seed 46；4 个 seed 差值全为正）→ 未检出差异，且能排除 >0.40pp 的劣化（`docs/research/benchmark/fourarm_seed_variance.md`）
  - R1 负结果已修正命题边界（**2026-11-23 再次收紧，审计 F5**）：原文写"替代的前提是域对齐"，**这个说法本身就没有证据支撑**——本仓的两个方向都失败了：跨域纯合成（R1）0.24 级、域对齐纯合成（协议对齐复跑的 R3pm）0.14 级，**都远低于真实基线**。而且把"域对齐"做成只差一个变量的臂后，它**显著更差**（−11.45pp，CI [−21.78, −1.13]）。所以能写的是：**「纯合成（无论是否做域对齐）在本域不可用；域对齐既未被证明是必要前提，也未被证明是充分条件」**。**⚠️ 2026-11-23 晚订正**：先前这里还写过"本项目的 SDG 生成器无法正确表达域对齐"——**这个诊断是错的**：R3-full 配方只调镜头/错位率/bays，**从没调过商品形状**，而朝向因子在生成器里是**能**表达的（PACK_W/PACK_H 是参数；真实域逐图中位宽高比 1.05 vs 合成 0.32）。"把朝向因子真的对齐过去有没有用"由 43 号形状先验臂单独回答。跨域纯合成 = 0.133 级失败（历史协议）不得外推。

## 三b、本项目后续自证 (2026-11-21~22, 真实数据 SKU-110K 到手后的实测)

上文的三条"硬规律"里，第 2 条 ("合成数量 ≠ 质量") 在本项目上得到了**直接实测**：

| 检验 | 结果 | 出处 |
|---|---|---|
| 合成能不能**替代**手工标注 (真实标注砍到 5% / 2%) | **不能**：追加 160 张合成后配对差值 95% CI = [−2.28, +2.48] pp (5% 预算)，缺口 10.12 pp，**能排除 ≤2.38 pp 的正向补回** | `docs/research/BUDGET_ARM_CONCLUSION_2026-11-21.md` §6b |
| **加大**合成剂量能不能补回 (40 ⊂ 80 ⊂ 160 嵌套子集) | **不能**：两条预算的剂量-反应都平坦且略负 (斜率 −0.16 / −1.03 pp 每 100 张) | 同上 §6c / `docs/research/benchmark/dose_response.md` |
| 机理 | 合成 21.8 框/图 vs 真实 147.0 框/图 (0.148×)，标注效率只有真实的 **1/6.7** | `docs/research/benchmark/domain_gap_measure.json` |
| 计数能力 | **该说法已被 2026-11-22 修正两次**：① 那个 MAE 29.1 用的是 2 epoch 冒烟权重，同 10 epoch 下 5% 标注是 20.76；② 再做成 3 seed 后 5% 臂 MAE = 20.76 / 29.59 / 25.44（std 4.42），全量真实 = 18.70 / 18.95 / 17.47（std 0.79），按 seed 配对的缺口 +6.89、95% CI [−4.02, +17.80] **跨 0** → 只能说"方向一致、幅度被 seed 方差支配"，不能写成"标注量上升直接换来 −36%" | `docs/research/benchmark/count_real1.json` / `budget_seed_variance.md` |

→ 对上文第一张表的修正：**"合成可替代训练集大规模手工标注"在本项目实测的域 (零售密集货架)
与规模 (≤160 张合成) 下不成立**；文献里的 "10–100 张真实微调" 结论来自**同域** (Isaac Sim 等
资产与目标一致) 的设置 —— 与本项目 "跨域 (参数化货架模板 vs 手机实拍密集货架)" 的前提不同，
**前提差异比方法差异更重要**。

## 四、风险清单

1. 域偏移下堆合成反效果（fruit 证据）→ 控制合成规模+分布对齐，不堆量。
2. 纹理/几何保真决定上限（本项目程序化贴图天花板 87–89 视觉分）→ 高保真需求走品牌资产包/摄影测量。
3. 合成 bbox 与人工 bbox 语义差（紧贴 vs 留边）→ P0-2 紧致框 + 分布一致性校验。
4. 评估闭锁：禁止用合成测试集证明合成价值（GPT 审计红线）。
5. 类别语义：SKU-110K 单类"object" 只能证明"定位/计数"，不能外推到品牌/SKU 识别（GPT 提醒）。
