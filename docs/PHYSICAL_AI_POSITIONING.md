# 物理 AI（Physical AI）归属研判：我们算不算？

定义来源（2026-11-08 核定）：NVIDIA Physical AI 词条与"三计算机"博客、IBM Think、ScienceDirect 数字孪生×物理AI 综述、产业案例（Unilever/Lowe's/Toyota/Advantech）。

## 一、权威定义拆解

NVIDIA 口径的 Physical AI = **端到端模型在物理世界感知→理解→推理→执行/编排动作**；工程栈 = 三计算机：
1. **训练计算机**（DGX）：真实/合成数据训基础模型与 CV 模型
2. **仿真与合成数据计算机**（Omniverse + Cosmos on RTX PRO）：数字孪生构建、域随机化合成数据、传感器仿真、仿真内 RL、software-in-the-loop 验证
3. **运行时计算机**（Jetson/DRIVE）：边缘实时感知-推理-执行闭环

使能件：OpenUSD（通用数据标准）、SimReady 资产（物理+语义元数据）、数字孪生、合成数据、世界基础模型（WFM）。

## 二、我们栈逐层对照

| Physical AI 栈层 | 要素 | 我们 | 判定 |
|---|---|---|---|
| 仿真/合成数据计算机 | 数字孪生资产（mm 几何+PBR+USD） | 13 SKU 孪生 + SimReady 式 sem/phys 元数据 + pxr 验证层栈 | ✅ 具备 |
| | 物理渲染合成数据+自动真值 | Cycles 光追 + 射线掩膜紧致框 + 可见面积过滤 + 状态机随机化 | ✅ 具备 |
| | 域随机化/场景多样性 | 光照 IBL 提取、相机抖动、四状态注入 | ✅ 部分（无材质级大规模随机化） |
| | 刚体动力学/传感器仿真 | 解析微扰等效；仅 RGB+掩膜 | ⚠️ 缺动力学与多传感器 |
| | 仿真内验证 | 渲染五闸+资产五闸+血缘+外部对抗评审（ESR 纪律） | ✅ 具备（超出多数案例） |
| 训练计算机 | 用合成数据训 CV 模型 | YOLO11n MPS 合成训练 + P0-1 四臂对照 | ✅ 具备（规模小） |

| 运行时计算机 | 边缘实时闭环执行 | 无部署闭环（看板为离线分析） | ❌ 缺 |
| embodied 交互 | 机器人策略/RL/actuation | 无 | ❌ 缺 |

## 三、结论

**我们 = Physical AI 栈中"仿真与合成数据计算机"层的 CPG 零售垂直实现——即物理 AI 的数据与孪生基座；属于物理 AI 范畴，但不是完整物理 AI 系统。**

- 产业口径支持：NVIDIA 自己把 Unilever（孪生产出商品图）、Lowe's（整店孪生）、Toyota（仓孪生+合成数据训叉车）归入零售/物流物理 AI 案例——它们的共同点正是"孪生+合成数据+视觉 AI"，与我们的形态同构。
- 差异化：我们的**证据链纪律（ESR：闸验收+血缘+外部对抗评审+负向对照）**是多数产业案例没有的；这正是"SimReady 之上"的北极星方向。
- 不可宣称：端到端物理 AI / 自主系统 / 世界模型 / 机器人能力——我们无 actuation、无运行时闭环、无动力学仿真。

## 四、向"完整物理 AI"演进的两步（如需）

1. **物理与传感器层**：接入刚体动力学（Isaac/PhysX 级掉落/堆叠）+ 深度/分割多传感器仿真，替换解析微扰；资产已 SimReady 化，迁移成本低。
2. **运行时闭环**：YOLO 巡检模型上边缘（Jetson/固定相机 agent）+ 真实回流主动学习闭环（与 P0-1/P2 批次天然衔接）。

## 五、定位话术（不过度宣称）

> "面向 CPG 零售的**物理 AI 数据与数字孪生基座**：以 OpenUSD 物理一致资产与光追合成数据，为感知模型提供零手工标注的训练真值，并以证据链闸（ESR）保证孪生与合成的可验收性——是物理 AI 栈中仿真与合成数据层的零售垂直实现。"
